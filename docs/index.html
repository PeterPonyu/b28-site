Abstract

Standalone text from the manuscript. No citations, no figure pointers.

Machine-learning classifiers on mass-spectrometry proteomics are routinely scored by random cross-validation, which mixes multi-cohort samples—and therefore acquisition batches—across the train/test split. On six CPTAC umich cohorts (CCRCC, LUAD, UCEC, HNSCC, LSCC, PDAC; 1,191 samples × 9,675 shared proteins), leave-one-cohort-out (LOGO) tumor-versus-normal classification yields pooled abundance AUROC 0.946 (95% cohort-cluster bootstrap CI 0.857–0.991; per-sample CI 0.931–0.958) with expected calibration error (ECE) 0.110.

A missingness-mask control is near chance (pooled AUROC 0.500), while a three-feature global-intensity summary already reaches 0.826, so only +0.12 is residual specific high-dimensional abundance. Per-cohort AUROC (0.794–1.000) and ECE (0.006–0.276) move inversely: overconfidence concentrates where transfer is hardest (PDAC, CCRCC). Random five-fold CV on the same data reports AUROC 0.993 and ECE 0.021 (ΔAUROC +0.047; ΔECE −0.089).

A patient-grouped five-fold arm that never splits a patient's tumor and matched .N normal matches sample-level random CV (AUROC 0.993, ECE 0.016), so pair-splitting does not explain the LOGO gap; a leaky-imputation null under LOGO is negligible. Confidence-ranked abstention raises retained accuracy from 0.845 to 1.000 at 10% coverage largely by selecting easy cohorts (≈47% LUAD + 49% LSCC; 0% PDAC/UCEC). Multi-cohort proteomic classifiers should use grouped splits and per-cohort calibration reporting. This is a high-effect methods audit, not a clinical biomarker claim.

Limitation-complete

Pearson r = −0.96 (two decimals; n = 6 is not a large-sample correlation). Exact permutation p = 0.0028 = 2/720. The unrounded least-squares value is −0.963 and is not treated as large-n precision. The gallery stops at four figures; a decorative 10×4 atlas is not part of this paper.
