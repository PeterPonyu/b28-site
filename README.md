# b28-site

Public GitHub Pages leaf for a proteomic tumor-versus-normal transfer evaluation under leave-one-cohort-out holdout.

- Live: https://peterponyu.github.io/b28-site/
- Repository: https://github.com/PeterPonyu/b28-site
- Archive: https://doi.org/10.5281/zenodo.21870024

This is not a published article and has no article DOI. The Pages leaf is a landing page only. It does not host results figures or numeric claims.

The tracked `docs/` directory is the Pages artifact. Push to `main` deploys it.
